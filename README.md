# หารตังกันบ่ (HanTanKanBo) 🧾✨

เว็บแอปคำนวณและหารค่าใช้จ่ายกับเพื่อน สไตล์เป็นกันเอง ทริปจบเงินจบ ช่วยคิดให้ว่าใครต้องโอนให้ใครรอบเดียวจบ ไม่ต้องโอนวนให้ปวดหัว!

🌐 **ใช้งานจริงได้ที่นี่ (Live Demo):** [https://yuttakans.github.io/HanTanKanBo/](https://yuttakans.github.io/HanTanKanBo/)

## 💡 ฟีเจอร์เด่น (Features)

1. **📸 แนบรูปสลิป / บิล พร้อมสแกนยอดเงินอัตโนมัติ (AI OCR)**:
   - อัปโหลดรูปสลิปโอนเงิน ใบเสร็จร้านอาหาร เซเว่น หรือบิลต่างๆ ได้ทันที (รองรับทั้งถ่ายรูปจากกล้องมือถือและเลือกไฟล์)
   - มีระบบอ่านตัวเลขยอดเงินรวม (Grand Total) และเติมลงช่องจำนวนเงินให้อัตโนมัติ ไม่ต้องเสียเวลานั่งพิมพ์เอง
   - มีระบบบีบอัดภาพอัตโนมัติในตัว (Canvas Resizing) ทำให้โหลดเร็ว ลื่นไหล ไม่กินแรมเครื่อง
   - บิลที่แนบไว้จะมีปุ่ม **"ดูรูปบิล"** ให้สมาชิกในกลุ่มกดเปิดดูหลักฐานบิลขนาดเต็มจอได้ตลอดเวลา
2. **01 แก๊งเรามีใครบ้าง?**: ใส่ชื่อเพื่อนร่วมชะตากรรมทริปนี้ ดึงเข้าตี้ได้รวดเร็ว
3. **02 ใครเปย์อะไรไปบ้าง?**: แปะบิลรัวๆ ใครจ่ายอะไรไป จดไว้ก่อน เลือกคนร่วมหารได้อิสระ
4. **03 สรุปยอดเคลียร์ใจ**: ระบบตัดหนี้วนรอบให้เรียบร้อย โอนรอบเดียวจบ เช็ครายคนได้ทันทีว่าใครรอดหรือใครต้องควักเพิ่ม
5. **ถ้าไม่ใช้เว็บนี้ ต้องโอนกันกี่รอบเนี่ย?**: โหมดจำลองความวุ่นวายถ้าต่างคนต่างโอน พร้อมตรวจจับคู่ที่โอนเงินสวนทางกัน
6. **ก๊อปปี้ส่งไลน์กลุ่ม**: สรุปยอดส่งเข้ากรุ๊ปไลน์เพื่อน ทวงแบบน่ารัก โอนครบเป๊ะ
